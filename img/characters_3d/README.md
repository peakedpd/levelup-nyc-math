# LevelUp characters: realistic video-game style (Canva AI, 2026-11-27)

Full-body, front-facing renders (1088×1456) made with Canva AI from each character's original 2D art.
Everyone wears basic white sneakers. Timberland boots are an XP upgrade in the clothing store (`timbs`, 150 XP). Theo keeps his Timberlands.
